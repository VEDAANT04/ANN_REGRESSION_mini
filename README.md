\# ANN Regression and Classification using PyTorch



This repository contains two mini projects developed while learning Artificial Neural Networks using PyTorch.



\## Projects



\### 1. ANN Regression



The regression project uses a Power Plant dataset to predict a continuous output using an Artificial Neural Network.



\### Workflow



\- Load and explore the dataset

\- Separate input features (`X`) and target (`y`)

\- Train-test split

\- Feature scaling using `StandardScaler`

\- Convert NumPy/Pandas data into PyTorch tensors

\- Create `TensorDataset`

\- Create `DataLoader`

\- Build the ANN architecture

\- Forward propagation

\- Calculate loss

\- Backpropagation

\- Update weights using an optimizer

\- Train for multiple epochs

\- Evaluate the model on test data



\### 2. ANN Classification



The classification project uses the Date Fruit dataset to classify samples using an Artificial Neural Network.



The project includes:



\- Data preprocessing

\- Feature scaling

\- PyTorch tensor conversion

\- ANN model creation

\- Model training

\- Classification and evaluation



\## Technologies Used



\- Python

\- PyTorch

\- Pandas

\- NumPy

\- Scikit-learn

\- Jupyter Notebook
